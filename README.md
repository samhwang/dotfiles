# Dotfile

Setting myself up for success, this will bootstrap any Linux/macOS machine that I come across. The name of the game is `Lean, mean, fighting machine`.

## Quick Start

- Clone the repo
- Clone the submodules
- Follow the `README.md` in the profile you need

```shell
git clone git@github.com:samhwang/dotfiles.git .dotfiles
cd .dotfiles
git submodule init
git submodule update --remote --recursive
```
